\# A3 - Marketplace E-commerce



Projeto acadêmico de Banco de Dados Relacional, desenvolvido como parte da avaliação A3.



\## Sobre o Projeto



Desenvolvimento de um banco de dados relacional para um marketplace de comércio eletrônico multivendedor.



O sistema contempla o gerenciamento de clientes, vendedores, produtos, categorias, pedidos, pagamentos, estoque e avaliações.



O objetivo é aplicar conceitos de modelagem de dados, normalização, integridade referencial, consultas SQL, índices, transações, concorrência, backup e segurança da informação.



\## Objetivos



\- Desenvolver o Diagrama Entidade-Relacionamento (DER).

\- Construir um modelo lógico normalizado até a Terceira Forma Normal (3FN).

\- Implementar o banco de dados utilizando PostgreSQL.

\- Criar scripts DDL, DML e DQL.

\- Aplicar índices e analisar o desempenho das consultas.

\- Demonstrar transações e controle de concorrência.

\- Implementar e testar backup e restauração.

\- Documentar práticas de segurança e adequação à LGPD.
